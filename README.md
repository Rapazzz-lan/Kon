# MangáStore (todos os arquivos na mesma pasta)

Precisa de **Node.js 22.13+**. Sem `npm install`.

    npm start        -> http://localhost:3000
    npm test         -> testes da regra de compra
    npm run db:reset -> recria o banco com dados de teste

Arquivos: index.html, style.css, app.js, api.js, carrinho.js (site) | server.js, compra.js, db.js (servidor) | schema.sql, seed.sql, resetar.js (banco) | compra.test.js (testes).

Atenção: o GitHub Pages NÃO executa o servidor Node. Para testar, use o Codespaces (ou rode no computador).
